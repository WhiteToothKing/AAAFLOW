## 系统简介

AAAFLOW 是专为游戏美术外包团队设计的 AI 赋能全流程工作流平台。系统通过智能体分析美术需求，自动路由到最佳 AI 生图模型（API 模式或 ComfyUI 工作流模式），极大提升美术生产效率。

### 核心特性

- **智能需求分析**：自然语言描述需求，AI 自动识别类型、风格、复杂度
- **多模型图像生成**：支持 DALL-E、Gemini、Midjourney、即梦、MiniMax、Banana Pro 等 API，以及 ComfyUI 本地/云端工作流
- **一站式工作流**：从需求提交到图片生成到评审反馈，全流程闭环
- **实时状态推送**：WebSocket 实时推送任务进度，无需手动刷新
- **PC 客户端**：基于 Electron 的 Windows 桌面应用，一键启动

## 快速开始

1. 打开 AAAFLOW 客户端（双击 AAAFLOW.exe）或访问 Web 端地址
2. 使用管理员分配的账号密码登录
3. 在工作台查看任务概览和快捷入口
4. 点击「提交需求」或「需求向导」创建第一个美术生成任务

---

## 登录与账户

- 在登录页面输入用户名和密码
- 勾选「记住我」可在下次自动填充用户名
- 如需修改 API 服务器地址，展开底部「API 服务器地址」面板
- 首次部署请管理员通过 `/api/auth/setup` 创建首个管理员账号

---

## 工作台（Dashboard）

工作台是您的日常起始页，展示：

- **欢迎卡片**：显示今日新任务数和总体统计
- **统计卡片**：总任务 / 生成中 / 已完成 / 失败 四大指标
- **最近任务**：最新 7 条任务的状态预览
- **快捷入口**：一键跳转到提交需求、AI 对话、需求向导、工作流管理

---

## 提交需求

1. 填写任务标题和需求描述（支持自然语言）
2. 可选择上传参考图片
3. 选择生成模式（API / ComfyUI 工作流）
4. 设置优先级
5. 点击提交后，系统自动进行：
   - AI 需求分析（类型、风格、复杂度识别）
   - 智能路由（选择最优生成服务）
   - 图像生成
6. 完成后在任务详情页查看生成结果

---

## 需求向导

适合对 AI 生图不太熟悉的用户，向导模式通过分步引导帮助您：

1. **描述需求**：用自然语言描述想要的图片
2. **选择类型**：系统推荐或手动选择美术类型（图标、角色、场景等）
3. **确认参数**：检查 AI 分析结果，可微调风格和参数
4. **提交生成**：一键提交，等待生成完成

---

## AI 对话

与 AI 智能体进行自然语言对话：

- 描述创意需求，AI 会推荐合适的技能和生成参数
- 上传参考图片进行风格匹配
- 对话中可直接创建任务
- 支持选择不同的 LLM 模型

## 任务列表

- 查看所有已提交的美术生成任务
- 按状态筛选（待处理 / 分析中 / 生成中 / 待评审 / 已完成 / 失败）
- 支持批量删除
- 点击任务标题进入详情页

## 任务详情

- 查看任务的完整信息（需求、类型、风格、生成服务）
- 查看所有生成结果的图片预览
- 对生成结果进行评分和反馈
- 重新生成（可附加改进建议）

## 常见问题

### Q: 登录后显示「未连上后台」？
检查后端服务是否正常运行。桌面版可在启动页点击「启动本地后台」。

### Q: 生成图片失败？
1. 检查对应 API 提供方的密钥是否已配置（管理员在 `.env` 中设置）
2. 如使用 ComfyUI，确认 ComfyUI 服务已启动且地址正确
3. 查看任务详情中的错误信息

### Q: 如何切换生图模型？
在提交需求时选择不同的生成模式，或在 AI 对话中让智能体推荐。

### Q: 桌面版如何更新？
系统会自动检测 GitHub Release 上的新版本，检测到更新后会弹出提示。
