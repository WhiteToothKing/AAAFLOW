# AAAFLOW 标准操作流程 (SOP)

> 本文档面向美术外包团队的一线员工，描述使用 AAAFLOW 完成美术需求的标准步骤。

---

## 总体流程

```
接到需求 → ① 整理素材 → ② 提交需求 → ③ AI 分析 → ④ 图片生成 → ⑤ 评审反馈 → ⑥ 二次修改
```

---

## 步骤详解

### 步骤 1：整理素材

收到美术需求后：

- [ ] 阅读甲方需求文档，明确关键要素
- [ ] 收集参考图（风格参考、色彩参考、布局参考）
- [ ] 整理需求描述（用自然语言，越详细越好）
- [ ] 确认美术类型：图标 / 角色原画 / 场景原画 / UI / 其他

**示例需求描述**：
> "需要一个魔法森林场景的游戏背景图，整体偏暗绿色调，有发光的蘑菇和萤火虫，画面远处有一座古老的精灵塔。风格参考宫崎骏系列，但更偏向暗黑系。"

### 步骤 2：提交需求到 AAAFLOW

**方式 A：快速提交**
1. 登录 AAAFLOW → 点击「提交需求」
2. 填写标题和需求描述
3. 上传参考图片（支持多图）
4. 选择优先级
5. 点击「提交」

**方式 B：向导模式（推荐新手）**
1. 登录 AAAFLOW → 点击「需求向导」
2. 按向导引导分步填写信息
3. 系统会自动推荐最佳参数
4. 确认后提交

**方式 C：AI 对话模式**
1. 进入「AI 对话」
2. 直接描述需求，AI 会引导你补充细节
3. AI 分析完成后可直接创建任务

### 步骤 3：等待 AI 分析

提交后系统自动执行：
- **需求分析**：AI 识别美术类型、风格、复杂度、关键元素
- **智能路由**：根据分析结果选择最佳生成服务
  - API 模式：适合通用场景（如即梦、MiniMax、DALL-E）
  - 工作流模式：适合特定场景（如 ComfyUI 定制工作流）

> 此阶段无需操作，通知中心会推送状态更新。

### 步骤 4：查看生成结果

1. 在工作台看到任务状态变为「已完成」
2. 点击进入「任务详情」
3. 查看 AI 生成的图片
4. 对比参考图和需求描述

### 步骤 5：评审反馈

对每张生成结果：
- **评分**（1-5 星）：整体满意度
- **文字反馈**：指出需要调整的地方
- **选定**：标记最满意的结果

如果不满意，可以点击「重新生成」并附加改进建议。

### 步骤 6：二次修改

拿到满意的 AI 生成图后：
1. 下载原始生成图
2. 在 PS/CSP 等专业软件中进行二次修改和精修
3. 按项目要求输出最终成品

## 不同需求类型的操作要点

### 游戏图标

- 需求描述重点：图标主题、尺寸比例、色调
- 推荐使用：即梦 / MiniMax（API 模式速度快）
- 提示词技巧：加上 "game icon, flat design, centered composition"

### 角色原画

- 需求描述重点：角色设定（性别、年龄、职业、装备）、画面构图
- 推荐使用：ComfyUI 角色工作流（精度更高）
- 提供正面 / 侧面参考最佳

### 场景原画

- 需求描述重点：场景类型、光照、氛围、建筑风格
- 推荐使用：Midjourney / DALL-E（大场景表现好）
- 提供多张不同角度参考效果更好

### UI/UED

- 需求描述重点：界面元素、配色规范、尺寸约束
- 推荐使用：即梦（UI 元素生成优秀）

## 常见操作

| 操作 | 入口 | 快捷键 |
|------|------|--------|
| 新建任务 | 工作台 → 新建任务 | Ctrl+Shift+N |
| 查看任务 | 任务列表 → 点击标题 | Ctrl+Shift+T |
| AI 对话 | 侧栏 → AI 对话 | Ctrl+Shift+C |
| 需求向导 | 侧栏 → 需求向导 | Ctrl+Shift+W |
| 回到工作台 | 侧栏 → 工作台 | Ctrl+Shift+D |

---

## 注意事项

1. **描述越详细，生成质量越高** — 不要只写"画一个角色"，要描述具体特征
2. **参考图是利器** — 上传 2-3 张风格参考能显著提升匹配度
3. **善用重新生成** — 附加反馈后重新生成通常效果更好
4. **关注通知中心** — 实时了解任务进度
5. **评分很重要** — 您的评分会帮助系统优化后续推荐
